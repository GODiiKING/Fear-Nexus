## 📖 Overview
Fear Nexus is a high-intensity survival experience. As Zizius, you are trapped in a world where fear is a weapon. Fight off waves of experimental undead, manage your resources, and survive the encroaching darkness.

## 🕹️ Controls
| Action | Key |
| :--- | :--- |
| Move Forward | W |
| Move Backward | S |
| Aim | Mouse Movement |
| Fire | Left Click |
| Restart | R (on Game Over) |

## 🚀 Key Features
* Dynamic Survival: Difficulty scales as you survive longer.
* Fluid Animation: Custom-rendered sprite sequences for movement and combat.
* Immersive Audio: Atmospheric soundscapes and reactive combat effects.
* Infinite Terrain: Seamlessly looping world architecture.

## 🛠️ Tech Stack & Structure
